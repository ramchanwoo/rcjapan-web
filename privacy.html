RCjapan

시행일 2026년 9월 12일

RCjapan 은 만든 사람이 혼자 쓰는 개인용 앱입니다. 이용자가 한 명이며, 그 한 명이 곧 이 앱을 만들고 운영하는 사람입니다.

1. 수집하는 정보

RCjapan 은 이용자가 유튜브 계정 연결을 승인한 경우에 한해, 유튜브 API 를 통해 다음을 읽고 씁니다.

  • 이용자 본인 계정의 재생목록 목록과 그 안의 항목
  • 재생목록에 담긴 영상의 ID · 제목 · 채널명 · 게시일

이름, 생년월일, 전화번호, 주소, 결제 정보는 수집하지 않습니다. 연락처 · 메일 · 사진 · 위치 정보에도 접근하지 않습니다.

2. 이용 목적

수집한 정보는 오직 다음 목적으로만 씁니다.

  • 이용자 본인 계정의 RCjapan 재생목록에 학습용 영상을 넣고 빼는 것
  • 이미 본 영상을 RCjapan_done 재생목록으로 옮기는 것
  • 영상 제목에서 일본어 단어를 뽑아 학습 우선순위를 정하는 것

광고에 쓰지 않고, 프로필을 만들지 않으며, 사람이 따로 열람하지 않습니다.

3. 저장 위치와 기간

모든 데이터는 이용자 본인의 컴퓨터 안에만 저장됩니다. 외부 서버로 보내지 않으며, 운영자가 관리하는 별도의 서버나 데이터베이스가 존재하지 않습니다. 접근 토큰과 갱신 토큰도 같은 컴퓨터의 설정 파일에만 저장됩니다.

보관 기간은 이용자가 직접 지울 때까지입니다.

4. 제3자 제공

어떤 정보도 제3자에게 제공하거나 판매하지 않습니다. 외부 분석 도구나 광고 네트워크를 쓰지 않습니다.

5. 구글 사용자 데이터에 대한 약속

RCjapan 이 구글 API 로부터 받은 정보의 이용과 다른 앱으로의 전송은 구글 API 서비스 사용자 데이터 정책을 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

6. 연결 해제와 삭제

언제든지 다음 방법으로 권한을 거둘 수 있습니다.

  • 앱 안의 유튜브 설정에서 연결 해제
  • 구글 계정 → 타사 앱 및 서비스에서 RCjapan 접근 권한 삭제

연결을 해제하면 저장돼 있던 토큰도 함께 지워집니다. 이미 재생목록에 담긴 영상은 유튜브 쪽 데이터이므로, 필요하면 유튜브에서 직접 지우면 됩니다.

7. 유튜브 이용약관

이 앱은 YouTube API 서비스를 사용합니다. 이용자에게는 YouTube 이용약관과 구글 개인정보처리방침이 함께 적용됩니다.

8. 변경

내용이 바뀌면 이 페이지에 바뀐 내용과 시행일을 올립니다.
